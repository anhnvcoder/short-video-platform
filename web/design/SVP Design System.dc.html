SVP Design System

Token đặt tên theo vai trò, khai báo trong svp-tokens.css, map sang Tailwind v4 + shadcn/ui ở cuối trang. Component chỉ nhận props, không màu cứng (ngoại lệ: lớp phủ trên video luôn dùng on-media). Màn hình: Mobile · Desktop.

Button · trạng thái

{{ sn.label }} {{ row.name }}

Focus: vòng 2 px ring cách 2 px (chỉ focus-visible). Pressed: scale 0.97. Disabled: surface-hover + muted + cursor:not-allowed. Loading: spinner + nhãn động từ (“Đang gửi…”), aria-busy.
